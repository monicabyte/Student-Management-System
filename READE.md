# Student Management System

A simple Java-based Student Management System using MySQL and JDBC.

## Technologies Used
- Java
- MySQL
- JDBC
- VS Code

## Features
1. Add Student
2. View Students
3. Search Student
4. Add Marks
5. View Marks
6. Record Attendance
7. View Attendance
8. Calculate Marks Percentage
9. Calculate Attendance Percentage
10. Exit

## Database
Database Name: student_management

Tables:
- students
- marks
- attendance

## Project Description
This project helps manage student details, marks, and attendance using Java and MySQL.
